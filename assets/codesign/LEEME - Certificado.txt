CERTIFICADO DE FIRMA - DISMA TRANSPORTATION
===========================================

QUE ES ESTO
  El .exe esta firmado con un certificado propio de Disma Transportation.
  Para que Windows lo reconozca (y no muestre "Unknown publisher"), hay que
  instalar la parte publica del certificado en el PC. Es un paso de UNA vez.

INSTALACION (una vez por PC / por usuario)
  1. Copia esta carpeta junto al .exe, o al menos estos dos archivos:
        Disma-CodeSign.cer
        Instalar certificado Disma.cmd
  2. Doble clic en "Instalar certificado Disma.cmd".
  3. Cuando Windows pregunte si quieres instalar el certificado, pulsa SI / YES.
  4. Listo. Abre "Facturacion MTM.exe": el editor debe salir como
     "Disma Transportation" y NO debe aparecer "Unknown publisher".

NOTAS
  - Es por USUARIO: no hace falta ser administrador.
  - Si Windows no muestra el aviso de confirmacion, revisa que el .cmd se
    ejecuto y que Disma-CodeSign.cer esta en la misma carpeta.
  - Para quitarlo: "Desinstalar certificado Disma.cmd".
  - El certificado vence en 2036. Si se vence o se cambia, hay que re-firmar
    el .exe y reinstalar el nuevo .cer en cada PC.

RE-FIRMAR DESPUES DE UN BUILD (desarrollador)
  - El certificado con clave privada es Disma-CodeSign.pfx (NO compartir;
    no se sube al repo).
  - Importarlo a Cert:\CurrentUser\My (doble clic en el .pfx > Actual usuario).
  - Ejecutar:  powershell -ExecutionPolicy Bypass -File sign_exe.ps1
  - Thumbprint: 76E57421C80055FF256CD4BE880B9377D5D9608F

LIMITES (importante, sin humo)
  - Esto elimina el aviso de "editor desconocido" en los PC donde se instala
    el certificado. En un PC ajeno donde no lo instalen, seguira saliendo.
  - SmartScreen (la pantalla azul "Windows protegio tu PC") se basa en
    REPUTACION; puede seguir saliendo en un PC nuevo aunque el certificado
    este instalado.
  - No existe un certificado gratuito reconocido mundialmente para firmar
    codigo. Este (autofirmado + instalado) es el metodo gratuito valido para
    uso interno. Para distribucion publica haria falta un certificado OV/EV
    o Azure Trusted Signing.
