========================================================
  FACTURACION MTM  -  LEEME PRIMERO
========================================================

CONTENIDO
  Facturacion MTM.exe     La aplicacion.

COMO USARLA
  1) Copia esta carpeta (o solo el .exe) a la PC.
  2) Abre "Facturacion MTM.exe".

NOTAS
  - No necesita instalar Python ni dependencias.
  - Funciona en Windows 10/11, tanto 32 como 64 bits.
  - Windows puede mostrar "Unknown publisher" la primera vez
    (SmartScreen) -> "Mas informacion" -> "Ejecutar de todas
    formas". Es normal en apps internas sin firma digital.
